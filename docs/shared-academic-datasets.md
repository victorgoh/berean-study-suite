# 📚 Academic Datasets & Provenance Directory

The **Berean Study Suite** is strictly built on **100% Public Domain** classical historical works and **Open-Access (Creative Commons Attribution-ShareAlike 4.0 / CC BY-SA 4.0)** academic datasets. No customized, proprietary, or non-public domain commentaries are included in the suite.

This document serves as the authoritative academic provenance catalog detailing every commentary set, Bible translation, lexicon, and reference encyclopedia integrated into the platform.

> [!NOTE]
> **Edge Database Sharding Architecture**:
> To ensure low latency and prevent memory allocation spikes under Cloudflare Worker limits (128 MB RAM on standard workers), oversized collections such as *The Pulpit Commentary* (`cPulpit`) and *The Biblical Illustrator* (`cBI`) are partitioned into 4 canonical volume shards (`_1`: Genesis–Esther, `_2`: Job–Malachi, `_3`: Matthew–Acts, `_4`: Romans–Revelation). The Berean service layer automatically routes incoming passage queries to the correct shard dynamically.
