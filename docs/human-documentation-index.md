## Documentation

Filenames identify the intended audience: `human-` documents are primarily for people, `agent-` documents are primarily for AI programming agents, and `shared-` documents are intended for both.

For in-depth details about the workflows, slash commands, and team structure, please refer to the files under the current directory:

- **[human-mcp-client-integration.md](human-mcp-client-integration.md)**: Complete MCP client integration guide.
- **[agent-stepbible-data-integration.md](agent-stepbible-data-integration.md)**: Compile, integrate, and deploy STEPBible datasets.

- **[shared-slash-commands.md](shared-slash-commands.md)**: Reference guide for slash commands and MCP tools.
- **[human-study-outputs.md](human-study-outputs.md)**: Guide to study outputs, images, and Word exports.
- **[shared-academic-datasets.md](shared-academic-datasets.md)**: Dataset provenance and licensing catalog.
